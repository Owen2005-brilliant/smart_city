# 中期补充实验：首次判断提前到第 2 分钟有帮助吗？

本实验重建共同评估样本，比较首湿后第 2、5 分钟单次判断，及各自允许 3 分钟后再判断一次的策略。所有策略统一观察到首湿后第 35 分钟。沿用纽约两输入逻辑回归（外推值＋潮汐站标记）、及时命中定义和按潮汐类型校准的原则。各方案在过去的可用样本上各自训练、选门槛。本实验属于已看过同一纽约快照后的探索性对照。数据来自 FloodNet (New York University and The City University of New York) 与 NYC DEP。
[事件](https://data.cityofnewyork.us/d/aq7i-eu5q) · [部署](https://data.cityofnewyork.us/d/kb2e-tjy3) · [Mydlarz et al. (2024)](https://doi.org/10.1029/2023WR036806)

## 主要结论

全量 3,581 场中有 3,064 场在 35 分钟窗口内有足够的真值支持，517 场缺乏完整支持。主测试期为 2026-07-01 至数据末尾（10-26），985 场事件中有 296 场升级，分属 18 个时间块。非潮汐站 429 场，其中 148 场升级。允许复查时，同误报预算下全样本及时命中 74 对 79，非潮汐站 14 对 10（早判在前）。非潮汐站增益是早判独有的 9 次减去晚判独有的 5 次。5%/10%/15%预算下，非潮汐站早判分别及时命中7/14/17次，晚判分别5/10/14次。相同预算比较按潮汐组分别取整并匹配误报次数。

在非潮汐站的后期样本，实际可评分且时间上尚能提前五分钟的升级事件，早判为50场、晚判33场。主比较的及时召回率差为 +2.70 个百分点；按天气时间块配对重采样1500次，95%区间约 −8.96 至 +5.20 个百分点。前一期（2026上半年）的组内等误报比较中，非潮汐站两种两阶段策略均无及时命中。冻结历史门槛后非潮汐站早判及时命中25场、误报70场；晚判及时命中18场、误报52场。对全网统一提前首判缺乏支持。保留默认第5分钟首判，并在独立后期数据上验证早判候选。

## 为什么总数与原型页不同

此前主要报告能在第5分钟发报且未来可核验的事件；这里将可核验但已越线、读数不足、或无法评分的事件也纳入共同分母，按原始曲线判断是否在首湿到35分钟期间升级。这些事件若未能及时告警，仍计入漏报或报晚。排名对照与固定门槛分别列出。用同批事件评估并不等于所有策略都能在所有事件中出分。早判和晚判都能出分的交集另报。此处模型与门槛在新的研究定义下重建，因此5分钟策略不等于对已发布检测器逐事件原样运行。

## 复现与文件说明

解压后在本目录内运行。使用 Python 3.14，依赖版本见 requirements.txt。

    python -m pip install -r requirements.txt
    python first_look.py --data-dir . --out result
    python make_figure.py --data-dir . --out result

first_look_protocol.txt 为运行前记录的方案。共同标签涵盖首湿到第35分钟（事件以零结束时可提前截止），以实测点为准，不插值。多站数据形成的时间块按事件重叠或间距≤24小时连接，为天气过程代理；无跨集合的块。每阶段仅用已收到的两个不同时刻的点求正涨速；阶段二还要求首判可出分、有新增观测、仍湿且未越线。训练时仅用及时正例和阴性，真实评分时所有升级都保留；两阶段首次评分扣除log(2)，是既有策略的固定偏移量。

- metrics.csv 同时包含四策略、两个时期、潮汐分组、全体/交集、匹配预算/冻结门槛、及时命中/报晚/漏报/误报。
- decisions.csv 与 truth.csv 按事件 key 可连接，time 是相对首湿的分钟数，空值表示未告警。peak 的单位为英寸，cross、last_low 均为分钟。逐例记录可解释早判抢回和丢掉的事件。
- availability.csv 记录可评分数、时间可达数、读数不足、已越线等原因；paired_intervals.csv 提供两阶段早判减晚判的及时召回率差的配对区间。
- cohort.json 保存原始快照 SHA-256。与 2026-11-10 下载版本一致。
- 图中两条实测曲线按历史期确定的门槛回放，是有目的的成功/误报示例。它们不用于代替全体估计。

推断限制：两项策略均未使用未来读数发警，但事件经过事后质检；历史测试结论对未观测的全天候误报率没有估计能力。重采样只覆盖测试时间块的不确定性，未重训模型。在后续期间检测新规则时，应保存其确定日期并避免反复针对同一测试期调参。
