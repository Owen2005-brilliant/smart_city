# 三篇论文方法在纽约街道积水数据上的比较

以下数字回答：对已开始积水且可评分的事件，在相同误报数下，多少次升级至少提前 5 分钟得到预警？后期为 2026 年 7 月 1 日至 10 月 26 日，前期为 2026 年上半年。用不同事件判断方法改进是否稳定。冻结的正式产品、GitHub 标签和独立验证协议沿用原版。

| 方法 | 后期全网 192 次升级，66 次误报 | 后期非潮汐 67 次升级，26 次误报 | 前期全网 77 次升级，44 次误报 | 前期非潮汐 11 次升级，24 次误报 |
|---|---:|---:|---:|---:|
| 项目规则：首判高门槛，允许复查 | 83 | 10 | 54 | 0 |
| EFAS 式：任一次达标即报 | 74 | 12 | 54 | 0 |
| EFAS 式：连续两次达标才报 | 70 | 4 | 49 | 0 |
| TEASER，公开实现适配 | 69 | 9 | 53 | 0 |
| 彰化研究的单站 RF＋时间注意力 LSTM 替代版 | 69 | 11 | 52 | 0 |

三种文献方法均使用相同的纽约事件、相同判断机会和相同评估定义，提取特征和作决定的机制不同。后期每个全网实验的分母为 859 场、其中 667 场未升级；非潮汐子集为 331 场、其中 264 场未升级。前期相应为 520 / 251 场。每组单独对齐误报数，全网和子组不相加。数据已用于历次探索，目前仍属历史评估。

## 方法来源和适配程度

- Casado-Rodríguez 等（2025）比较集合预报概率门槛与连续确认。纽约实验采用 1 次达标或连续 2 次达标的发警逻辑，以纽约评分替代 EFAS 集合流量预报；三条规则共享评分器。[论文](https://doi.org/10.1175/JHM-D-24-0054.1) · [作者代码](https://github.com/casadoj/EFAS_skill)
- Schäfer 和 Leser 的 TEASER（2020）用可靠性分类器和连续预测决定停止时刻。本实验运行 aeon 1.3.0 公开实现，换用适合极短前缀的随机森林，保留单类 SVM 和停止判断。第 2 分钟只做内部预测，不向外告警。训练时按天气过程分折，只用对应时刻已出现的前缀。分类器决定在第 5 或 8 分钟停止后，再将升级分数统一映射到实验误报预算；按原生标签发警的结果另列 native。第 8 分钟无有效观测则没有第二次发报机会。[论文](https://doi.org/10.1007/s10618-020-00690-z) · [本次使用的实现](https://github.com/aeon-toolkit/aeon/blob/v1.3.0/aeon/classification/early_classification/_teaser.py)
- Chang 等（2024）的原系统由随机森林和 STA-TGLSTM 组成，使用多站水深、雷达雨量，预测未来三小时。此处没有同期对齐的雷达雨量及多站连续序列，故只比较受其两阶段设计启发的单站方法，用随机森林估计升级概率，时间注意力 LSTM 在训练期升级样本中预测各时段峰值，最后用概率乘预测峰值排序。未实现原模型的空间注意力和变换门。峰值回归阶段的增量见 Taiwan_RF_only 对照。不可将本表用于声称胜过彰化原版模型。[论文](https://doi.org/10.1016/j.ijdrr.2024.104263)

## 稳定性和调整方向

- 后期全网相对 TEASER 增加 14/192，即 +7.3 个百分点。按 18 个天气时间块作 1,000 次配对重采样，每次重新对齐误报，差值 95% 百分位区间约 +1.1 至 +13.9 个百分点；前期差值仅 +1/77，区间跨零。区间以已训练模型为条件，未计入多轮探索与训练不确定性。
- 固定早先验证期的门槛后，后期全网“及时命中 / 误报”为本项目 96 / 127、EFAS 任一次 92 / 136、EFAS 连续两次 86 / 134、TEASER 90 / 146、彰化单站替代 93 / 163。这里各方法误报不同；数值来自统一实验阈值协议，已部署产品使用自己的冻结门槛。
- 后期全网，去掉 TEASER 可靠性停止条件、保留同组前缀模型时，等误报及时命中 70，使用停止条件为 69。彰化单站替代版去掉 LSTM 后全网也是 69。两类复杂模块均未给本期全网增加及时命中；外地模型的输入和任务在原场景更丰富。
- 非潮汐站放宽第 5 分钟首判门槛在后期回看有 2 场增益，但选择门槛必须用更早数据。对照验证期按同误报比较，两个训练划分分别是 0 对 0、1 对 1，按预先约定的平局规则两次均保留正式规则。先保留原算法，把放宽首判作为未来候选，无需修改已发布的独立检验。

## 运行和核对

实测环境为 macOS arm64、Python 3.11.13、CPU。运行以下命令，逐场输入和研究代码随包提供。图表 PNG 已直接附在包内。

    python3.11 -m venv env
    source env/bin/activate
    python -m pip install -r requirements.txt
    python benchmark.py ../../nyc --out rerun
    python check.py rerun

result/metrics.csv 有等误报、过去锁定阈值、TEASER 原生分类三种口径。result/decisions.csv 是五分钟及时命中、告警时刻和事件标识的逐场账本。result/paired_intervals.csv 的方向为本项目减对照；重采样忽略无正例或无法对齐预算的样本。result/diagnostics.json 记录验证期非潮汐门槛选择及 TEASER 第 5 分钟已作出正或负决策的场数。protocol.md 记录建模设定。数字分别经检查：同一列各方法事件键完全一致；误报预算吻合；既有三条规则在前后期、全网和非潮汐的 12 项及时命中数复现。

作者归属 FloodNet（NYU、CUNY）与 NYC DEP 的事件及站点数据：[事件表](https://data.cityofnewyork.us/d/aq7i-eu5q) · [部署表](https://data.cityofnewyork.us/d/kb2e-tjy3)。项目的 [中期冻结标签](https://github.com/Owen2005-brilliant/smart_city/tree/midterm-freeze-v1) 提供原始数据下载信息、训练边界及告警定义。
